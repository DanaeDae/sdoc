#### 这张图想要说明什么？
这张图完美地解释了“看不见的认知过程”是如何产生“看得见的数据结果”的。这张图就是计算机科学家和心理学家用来“拆解人类大脑如何做决定”的神奇工具。

- 连接微观与宏观：单次的波浪线（微观的随机过程）经过大量叠加后，就形成了上面和下面那两条平滑的曲线（宏观的统计分布）。

- 解释速度与准确率权衡（Speed-Accuracy Tradeoff）：通过调整图中的阈值（a）、漂移率（v）、偏差（z），模型可以完美模拟出人类为什么有时快而不准，有时慢而准。

- 数据拟合：在科研中，科学家会记录受试者的实际反应（反应时间和是对是错），然后把这些数据扔进 DDM 模型中，反推计算出受试者的参数（v, a, z, t）。以此来判断受试者做决定慢是因为“证据积累慢（v小）”、“太谨慎（a大）”、“有偏见（z偏）”，还是“单纯手速慢（t长）”。

#### 骨架
- 横轴 (time)：代表时间。从左向右，时间流逝。
- 纵轴：代表“证据累积量”（Evidence Accumulation）。大脑在做决定时，收集支持某个选项的证据的多少。
- Upper / Lower response boundary（上/下反应边界）：两条黑色的水平线是决策阈值。
        - 当证据累积触碰（或跨越）上边界时，大脑做出“正确”或“选择A”的决定。
        - 当证据累积触碰下边界时，大脑做出“错误”或“选择B”的决定。

- Threshold (a) 阈值：上下边界之间的总距离。**阈值越大，代表决策越谨慎（需要更多证据才做决定），反应更慢但更准确；阈值越小，代表越冲动，反应快但容易错**。

#### 关键参数
- Drift rate (v) 漂移率：中间那个箭头的斜率。代表证据累积的平均速度和方向。漂移率越大，证据累积越快，决策越快且越准确。如果任务很简单，漂移率就大；任务很难，漂移率就小（箭头更平缓）。
- Bias (z) 起始偏差：起始点不在正中间，而是偏上或偏下。代表在决策开始前，大脑的先验偏好（比如更倾向于选A，或者A出现的概率本身就大）。
- Non-decision time (t) 非决策时间：在到达起始点之前的那段时间。这代表刺激编码和运动执行的时间（比如你看到屏幕上的字，到你手指按下去，大脑处理视觉和发出运动指令的时间）。**这部分时间内，大脑不进行证据累积**。

#### 红蓝线
##### 中间位置锯齿状-红蓝线
中间那些锯齿状的蓝色线和红色线，叫做**单次试次的决策轨迹（Single-trial trajectories）**。代表了每一次具体的决策过程。由于大脑在处理信息时存在“神经噪声”，所以我们每次收集证据的过程并不是完美的直线，而是像“犹豫不决”一样上下波动。波动大小这反映了单次决策中的随机性和不确定性。

- 蓝色波浪线：代表某一次具体的决策中，证据不断累积，最终碰到了上边界（比如做对了）。
- 红色波浪线：代表某一次具体的决策中，证据累积碰到了下边界（比如做错了）。

##### 上下方平滑-红蓝线（ Response density）
上下方平滑-红蓝线叫做**反应时间密度分布曲线（Response density / RT distribution）**。它们是宏观的统计结果。如果我们把几百次、几千次实验里所有“蓝色波浪线”碰到上边界的时间点统计起来，画一个直方图/概率分布图，就成了上面这条平滑的蓝色曲线；同理，所有“红色波浪线”碰到下边界的时间统计起来，就成了下面的红色曲线。

- 蓝色曲线：代表所有做出“上边界”选择（比如正确反应）的概率随时间的变化。曲线越高，说明在这个时间点做出该反应的人最多。
- 红色曲线：代表所有做出“下边界”选择（比如错误反应）的概率随时间的变化。

本图中，蓝色曲线比红色曲线高且靠左，这说明在这个例子中，大脑更倾向于、也更快速地做出“上边界”的反应。

### 历史脉络

1. **统计起源**  
   最早可追溯到 Wald（1940s）的**序贯概率比检验（SPRT）**：在噪声数据下最优地决定两个假设。它本质上就是带边界的随机游走。

2. **心理学中的离散随机游走模型**（1960s–1970s）  
   Stone (1960)、Laming (1968)、Link & Heath 等人把随机游走引入认知决策：证据每一步离散累积，直到碰到上/下边界。这些模型已经能同时解释正确率和反应时，但预测正确与错误反应时分布相同（当起点居中时），与实际数据不符。

3. **连续扩散模型的出现（Ratcliff, 1978）**  
   Roger Ratcliff 提出用 **连续时间的维纳过程（带漂移的布朗运动）** 来代替离散随机游走。理由主要有两点：
   - 大脑证据累积更自然地被视为连续过程，而不是一步一步跳。
   - 连续极限下，首达时间密度有漂亮的解析形式（我们推导的级数解和逆高斯近似），更容易拟合完整的 RT 分布。

   这就是今天所说的标准 **DDM / Diffusion Decision Model**。后来又加入了跨试次变异（漂移率、起点、非决策时间的变异），以解释“错误反应往往更慢”等现象。

### 核心思想一句话总结

DDM 的本质就是：  
**决策 = 噪声证据的连续随机游走（扩散过程），直到累积到某个决策边界。**
推导的每一步，都是把这个想法从离散概率变成可计算的连续数学工具的过程。

### 数学推导
离散随机游走 → 连续极限得到带漂移的布朗运动（SDE）→ Fokker-Planck 方程 → 吸收边界下的首达时间密度

---

### 第 1 步：离散随机游走（最底层）

考虑一维格子上的粒子。时刻 \(n = 0,1,2,\dots\)，位置为 \(S_n\)。

- 每次独立地以概率 \(p\) 向右走 1 步，以概率 \(q = 1-p\) 向左走 1 步。
- 起始位置 \(S_0 = z\)（整数）。

递推关系：
\[
S_{n+1} = S_n + \xi_{n+1},
\]
其中 \(\xi_i\) 是独立同分布的随机变量：
\[
\mathbb{P}(\xi_i = +1) = p, \qquad \mathbb{P}(\xi_i = -1) = q.
\]

期望与方差：
\[
\mathbb{E}[\xi_i] = 2p-1, \qquad \mathrm{Var}(\xi_i) = 4pq.
\]

经过 \(n\) 步后：
\[
\mathbb{E}[S_n] = z + n(2p-1), \qquad \mathrm{Var}(S_n) = n\cdot 4pq.
\]

这就是**有偏随机游走**（biased random walk）。当 \(p = 1/2\) 时退化为无偏随机游走。

---

### 第 2 步：连续极限 —— 从离散到连续（中心极限定理 + 缩放）

我们希望把“步数 \(n\)”变成连续时间 \(t\)，把“位置”变成连续变量 \(X(t)\)。

引入时间步长 \(\Delta t > 0\) 和空间步长 \(\Delta x > 0\)，令：
\[
n = \frac{t}{\Delta t}, \qquad S_n = X(t).
\]

要求在 \(\Delta t \to 0\)、\(\Delta x \to 0\) 时，期望与方差都收敛到有限值。因此必须对漂移和扩散进行正确的缩放：

设
\[
p = \frac12 + \frac{v}{2s}\sqrt{\Delta t} \quad (\text{或等价形式}),
\]
并令
\[
\Delta x = s\sqrt{\Delta t}.
\]

则一步的期望增量：
\[
\mathbb{E}[\Delta X] = (2p-1)\Delta x = v\,\Delta t,
\]
方差：
\[
\mathrm{Var}(\Delta X) = 4pq\,(\Delta x)^2 \approx s^2\,\Delta t.
\]

由中心极限定理，当 \(\Delta t \to 0\) 时，\(X(t)\) 收敛到**带漂移的布朗运动**（Wiener 过程）：
\[
X(t) = z + v t + s W(t),
\]
其中 \(W(t)\) 是标准维纳过程（标准布朗运动），满足：
\[
\mathbb{E}[W(t)] = 0, \qquad \mathrm{Var}(W(t)) = t, \qquad \text{独立增量}.
\]

用微分方程的语言写就是 **Itô 随机微分方程（SDE）**：
\[
dX(t) = v\,dt + s\,dW(t), \qquad X(0) = z.
\]

这就是从微观随机游走到宏观连续过程的核心极限。

---

### 第 3 步：转移概率密度与 Fokker-Planck 方程

现在我们关心：在时刻 \(t\)，粒子位于 \(x\) 附近的概率密度 \(g(x,t)\)。

对任意光滑测试函数 \(f\)，由 Itô 公式：
\[
\mathbb{E}[f(X(t+\Delta t))\,|\,X(t)=x] = f(x) + \bigl(v f'(x) + \tfrac12 s^2 f''(x)\bigr)\Delta t + o(\Delta t).
\]

两边对初始分布求期望，并令 \(\Delta t\to 0\)，就得到**前向 Kolmogorov 方程**（Fokker-Planck 方程）：
\[
\frac{\partial g}{\partial t} = -v\frac{\partial g}{\partial x} + \frac{s^2}{2}\frac{\partial^2 g}{\partial x^2}.
\]

初始条件：
\[
g(x,0) = \delta(x-z).
\]

无边界时，这个方程的解就是著名的高斯密度：
\[
g(x,t) = \frac{1}{s\sqrt{2\pi t}}\exp\Bigl(-\frac{(x-z-vt)^2}{2s^2 t}\Bigr).
\]

---

### 第 4 步：吸收边界与首达时间

在决策模型中，一旦证据累积到上边界 \(a\) 或下边界 \(0\)，决策立即终止。这对应**吸收边界条件**：
\[
g(0,t) = 0, \qquad g(a,t) = 0.
\]

粒子第一次碰到边界的时间
\[
\tau = \inf\{t>0 : X(t)=0\text{ 或 }X(t)=a\}
\]
称为**首达时间（First Passage Time, FPT）**。

首达时间的概率密度函数 \(g_\pm(t)\) 就是边界上的**概率通量**（probability flux）：
\[
g_+(t) = \frac{s^2}{2}\frac{\partial g}{\partial x}\Big|_{x=a}, \qquad
g_-(t) = -\frac{s^2}{2}\frac{\partial g}{\partial x}\Big|_{x=0}.
\]

（上边界通量为正，下边界通量为负，取绝对值后得到密度。）

---

### 第 5 步：求解首达时间密度 —— 分离变量法

在吸收边界下，用分离变量法求解 Fokker-Planck 方程。

设
\[
g(x,t) = e^{\alpha x + \beta t}\,u(x,t),
\]
选择 \(\alpha,\beta\) 消掉一阶导数项，把方程变成标准热方程，再把 \(u\) 展开成正弦级数（因为边界为零）：
\[
u(x,t) = \sum_{k=1}^\infty c_k\sin\Bigl(\frac{k\pi x}{a}\Bigr)e^{-\lambda_k t}.
\]

经过计算，最终得到**下边界首达时间密度**的无穷级数形式（\(s\) 一般情形）：
\[
g_-(t) = \frac{\pi s^2}{a^2}\,e^{-2vz/s^2}\sum_{k=1}^\infty k\sin\Bigl(\frac{k\pi z}{a}\Bigr)
\exp\Bigl[-\frac12\Bigl(\frac{v^2}{s^2}+\frac{k^2\pi^2 s^2}{a^2}\Bigr)t\Bigr].
\]

上边界密度 \(g_+(t)\) 只需做对称变换：
\[
v\to -v,\qquad z\to a-z.
\]

这就是精确的解析解。实际计算时用有限项截断即可，收敛很快。

---

### 第 6 步：单边界极限 —— 逆高斯分布

若只考虑一个边界（例如下边界很远，或只有上边界），则首达时间精确服从**逆高斯分布**：
\[
g(t) = \frac{z}{s\sqrt{2\pi t^3}}\exp\Bigl(-\frac{(z-vt)^2}{2s^2 t}\Bigr).
\]

这是两边界级数解在 \(a\to\infty\) 时的极限。

---

### 第 7 步：选择概率（积分掉时间）

对首达时间密度在时间上积分，得到最终选择某一边界的概率：
\[
P_- = \int_0^\infty g_-(t)\,dt = \frac{e^{-2va/s^2}-e^{-2vz/s^2}}{e^{-2va/s^2}-1}
\quad(v\neq 0).
\]

\(v=0\) 时退化为 \(P_- = z/a\)。

---

### 整条逻辑链

1. **离散随机游走** → 每一步独立的 ±1 跳跃。  
2. **正确缩放**（\(\Delta x\sim\sqrt{\Delta t}\)）+ 中心极限定理 → 连续漂移布朗运动 \(dX = v\,dt + s\,dW\)。  
3. **Itô 公式** → Fokker-Planck 方程（概率密度的演化）。  
4. **吸收边界** → 首达时间 = 边界通量。  
5. **分离变量** → 首达时间密度的无穷级数。  
6. **时间积分** → 选择概率的闭式解。
